보안담당자 스트레스 해소용 "무쌍(1 vs 1000) 액션" 브라우저 게임의 콘텐츠 데이터를 만들어줘.
플레이어는 야근에 지친 보안담당자. 취약점·바이러스·웜·버그·랜섬웨어 등을 수백 마리씩 쓸어버린다.
톤: 한국 직장인 보안팀 공감 유머 + 통쾌함. 욕설 금지, 실존 인물·회사 비하 금지.

아래 JSON 하나만 출력해(코드펜스 없이, 주석 없이, 유효한 JSON):
{
  "enemyQuips": {            // 적이 죽을 때 머리 위에 뜨는 짧은 비명/대사 (각 12개, 2~10자)
    "bug": [], "worm": [], "virus": [], "trojan": [], "botnet": [], "ransom": [], "rootkit": []
  },
  "playerShouts": [],        // 콤보/필살기 때 플레이어 외침 20개 (2~14자) 예: "패치 완료!"
  "musouShouts": [],         // 무쌍 발동 외침 8개 (10~24자) 예: "전사 긴급 패치 배포!!!"
  "commands": [],            // 타이핑 필살기용 리눅스/보안 명령어 30개. 실제 명령 형태, 8~28자, 영문 소문자/숫자/기호(- / . _ 공백)만. 예: "kill -9 malware", "iptables -A INPUT -j DROP"
  "bases": [],               // 전장 거점 이름 6개 (2~8자) 예: "DMZ", "사내 메일서버"
  "officers": [              // 중간 보스급 '적장' 8명
    {"name": "적장 이름(2~12자, 실존 악성코드/취약점 이름 차용 가능 예: Heartbleed)", "title": "칭호(4~12자)", "enter": "등장 대사(8~30자)", "die": "격파 대사(4~20자)"}
  ],
  "boss": {"name": "최종보스 이름", "title": "칭호", "enter": "등장 대사", "phase2": "2페이즈 대사", "die": "격파 대사"},
  "stageIntro": [],          // 스테이지 시작 전 상황 브리핑 문장 4개 (각 20~50자, 보안관제 알림 말투)
  "resultComments": [        // 결과화면 코멘트. 스트레스 해소율 구간별 3개씩
    {"min": 0, "lines": []}, {"min": 40, "lines": []}, {"min": 80, "lines": []}, {"min": 100, "lines": []}
  ],
  "tips": []                 // 로딩/타이틀 팁 10개 (조작법·보안 개그 섞어서, 15~45자)
}
