너는 보안 교육 기획자다. 무쌍 액션 게임에 "침해사고 대응 훈련" 미션 모드를 넣는다. 시나리오: 사내에 랜섬웨어가 퍼지기 시작했다.
NIST SP 800-61 침해사고 대응 절차(준비 / 탐지·분석 / 격리·제거·복구 / 사후 활동)를 게임 스테이지 6개로 구성해라.
게임에서 가능한 행동: 특정 적 처치, 특정 구역 사수(버티기), 로그 분석 3지선다, 보안 명령어 타이핑, 아이템 운반, 보스(적장) 격파.

파일을 만들거나 수정하지 말고, 셸 명령도 쓰지 말고, 아래 JSON 하나만 응답 본문으로 출력해라(코드펜스·설명 없이):
{
  "title": "미션 제목",
  "stages": [
    {
      "phase": "탐지·분석",          // NIST 단계명
      "name": "스테이지 이름(2~12자)",
      "brief": "관제 브리핑(30~70자, 상황 설명)",
      "objective": "게임 목표 문구(10~30자)",
      "action": "kill | hold | log | type | carry | boss 중 하나",
      "lesson": "이 단계에서 실무자가 꼭 해야 할 일(40~90자)",
      "mistake": "실무에서 흔한 실수(30~70자)"
    }
  ],
  "reportChecklist": ["사후 보고서에 들어가야 할 항목 6개(각 20자 이내)"],
  "officeMobs": [   // 직장 스트레스를 형상화한 엘리트 적 6종. 실존 인물·회사 비하 금지, 공감 유머.
    {"name": "적 이름(2~10자, 예: 긴급 회의 소집)", "die": "격파 시 대사(4~16자)", "taunt": "등장 대사(6~20자)"}
  ]
}
