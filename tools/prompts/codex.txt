너는 보안 교육 콘텐츠 기획자다. 보안담당자용 "무쌍 액션 게임"에 들어갈 취약점 학습 데이터를 만든다.
게임 구조: 전장에 OWASP Top 10 기반 거점 6개가 있고, 각 거점의 '거점관리자'(취약점 의인화)를 쓰러뜨리면 도감 카드가 해금되고 3지선다 퀴즈가 나온다. 시간마다 실존 CVE '적장' 8명이 등장하고, 쓰러뜨리면 CVE 카드가 뜬다.

정확성이 최우선이다. CVE 번호·CVSS 점수·영향 제품은 실제 사실만 쓴다. 불확실하면 그 항목을 빼라.
파일을 만들거나 수정하지 말고, 아래 JSON 하나만 응답 본문으로 출력해라(코드펜스·설명 없이, 유효한 JSON):

{
  "bases": [   // 정확히 6개
    {
      "id": "injection",                 // 영문 소문자 id
      "owasp": "A03:2021 Injection",      // OWASP Top 10 2021 표기
      "cwe": "CWE-89",                    // 대표 CWE
      "base": "인젝션 요새",              // 거점 이름 (2~8자)
      "keeper": "SQL 인젝션",             // 거점관리자 이름 (취약점명)
      "summary": "한 문장 설명 (30~70자)",
      "attack": "공격 예시 한 줄 (페이로드/시나리오, 60자 이내)",
      "defense": ["방어법1 (40자 이내)", "방어법2", "방어법3"],
      "quiz": {"q": "질문 (60자 이내)", "choices": ["보기1", "보기2", "보기3"], "answer": 0, "explain": "해설 (80자 이내)"}
    }
  ],
  "cves": [    // 정확히 8개, 유명한 실존 CVE
    {
      "name": "Log4Shell",                // 통칭
      "cve": "CVE-2021-44228",
      "cvss": 10.0,
      "product": "Apache Log4j 2",
      "summary": "무슨 취약점인지 한 문장 (70자 이내)",
      "fix": "대응 한 문장 (60자 이내)",
      "quiz": {"q": "...", "choices": ["...","...","..."], "answer": 1, "explain": "..."}
    }
  ]
}
bases는 인젝션, 접근통제 실패(IDOR 등), 암호화 실패, 취약/구버전 컴포넌트, 인증 실패, SSRF 를 다뤄라.
quiz의 answer 위치(0/1/2)는 골고루 섞어라. 모든 텍스트는 한국어(고유명사·코드 제외).
