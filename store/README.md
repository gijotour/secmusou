## 2. 스토어 등록정보

**간단한 설명** (80자 이내, 72자)

> 거대한 키보드로 버그·랜섬웨어를 쓸어버리며 OWASP Top 10, 실존 CVE, 로그 분석을 익히는 보안 학습 액션 게임입니다.

**자세한 설명**

```
야근에 지친 보안담당자가 거대한 기계식 키보드를 들고 버그·웜·바이러스·랜섬웨어를 수백 마리씩 쓸어버리는 무쌍 액션 게임입니다.
싸우는 사이에 OWASP Top 10 취약점, 실제로 악용된 CVE, 로그 읽는 법, 침해사고 대응 절차가 자연스럽게 손에 붙습니다.
회원 가입 없이 바로 시작합니다. 광고와 앱 내 구매가 없습니다.

【싸우는 동안 쌓이는 보안 지식】
- 거점 6곳 = OWASP Top 10: 인젝션, 접근통제 실패, 암호화 실패, 취약 컴포넌트, 인증 실패, SSRF 거점을 되찾습니다. 거점관리자를 쓰러뜨리면 설명·공격 예시·방어법이 담긴 도감 카드와 3지선다 퀴즈가 나오고, 맞히면 버프를 받습니다.
- 적장 = 실제로 악용된 CVE: Log4Shell, Heartbleed, EternalBlue, MOVEit, XZ Utils 등 기본 10종에, 매달 미국 CISA 의 「실제 악용 취약점 목록(KEV)」에 새로 오른 것 가운데 4종이 새 적장으로 들어옵니다.
- 로그 분석 보스전: 적장의 체력이 절반이 되면 Apache·sshd·Windows 이벤트·DNS 같은 실제 형식의 로그 한 줄이 뜹니다. 공격 유형을 맞히면 적이 잠시 무력해집니다.
- 터미널 필살기: 화면에 뜬 실제 보안 명령어(방화벽 규칙, 패키지 감사 등 27종)를 그대로 타이핑하면 화면 전체를 쓸어버립니다. 명령마다 무엇을 막는지 설명이 붙습니다.
- 침해사고 대응 훈련 모드: 랜섬웨어 사고를 NIST SP 800-61 절차에 맞춰 6단계로 실습합니다. 단계마다 실무 포인트와 흔한 실수 카드가 나오고, 마지막에 사후 보고서 체크리스트를 보여 줍니다.
- 공부할수록 강해지는 구조: 도감을 모으면 무기 6종이 차례로 열립니다. 문제은행 61문제는 입문·실무·심화 난이도로 고르고, 틀린 문제는 다음 판에 더 자주 나옵니다(오답노트).

【이런 분께】
- 보안담당자: 「긴급 회의 소집」「퇴근 직전 요청」 같은 직장 스트레스 몹까지 쓸어버리며 풀고, 그사이 놓친 개념을 복습합니다.
- 보안 입문자: OWASP Top 10 과 대표 CVE 를 카드·퀴즈·로그로 처음 익힙니다.
- 보안팀 교육: 침해사고 대응 훈련 모드로 대응 순서를 몸으로 익힙니다. 정답·오답이 남아 무엇을 다시 볼지 알 수 있습니다.

【조작】
- 왼쪽 가상 조이스틱으로 움직이고, 오른쪽 버튼으로 공격·강공·대시·무쌍·터미널을 씁니다. 조준은 가까운 적에게 자동으로 맞춰집니다.
- 가로 화면으로 즐깁니다.
- 한 번 열어 두면 인터넷 없이도 실행됩니다.

【미리 알려 드립니다】
- 기록과 도감은 이 기기에만 저장됩니다. 다른 기기로 옮겨지지 않고, 앱을 지우면 함께 지워집니다.
- 휴대폰에서는 해상도·적 수·효과를 자동으로 줄여 가볍게 돌립니다. 오래된 휴대폰에서는 움직임이 느릴 수 있습니다.
- 터미널 필살기는 영문 키보드로 입력합니다.
```
