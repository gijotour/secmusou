# 보안무쌍 (SECURITY MUSOU)

보안담당자를 위한 **스트레스 해소 + 보안 학습** 무쌍 액션 게임입니다.
야근에 지친 보안담당자가 거대한 기계식 키보드를 들고 버그·웜·바이러스·랜섬웨어를 수백 마리씩 쓸어버립니다.
그러면서 OWASP Top 10 취약점, 실존 CVE, 악성코드 유형별 대응법을 자연스럽게 익힙니다.

## 실행

`index.html` 을 브라우저(Chrome/Edge)로 열면 됩니다. 설치는 필요 없습니다.

- 3D(Three.js)는 CDN에서 불러옵니다. 인터넷이 없으면 자동으로 **2D 탑뷰**로 실행됩니다.
- 로컬 서버로 열 때: `python -m http.server 5173` 후 http://localhost:5173

## 조작

| 키 | 동작 |
|---|---|
| W / S | 앞 / 뒤 이동 |
| A / D | 옆걸음 |
| ← → | 시점 회전 (화면을 클릭하면 마우스 시점: 좌클릭 J, 우클릭 K) |
| **J** | 약공격 (최대 5연타) |
| **K** | 강공격. J를 n번 친 뒤 K를 누르면 다른 기술이 나갑니다 (예: JJJJ+K = ENTER 키 강타) |
| L / Shift | 대시 (무적) |
| **SPACE** | 무쌍 난무 (게이지가 가득 찼을 때, J 연타로 시간 연장) |
| **E** | 긴급 터미널: 화면의 보안 명령어를 그대로 타이핑하면 화면 전체 섬멸 |
| V | 시점 전환: 3인칭(등 뒤) → 1인칭 → 쿼터뷰 → 2D |
| 1~6 | 무기 교체 (해금된 것만) |
| ESC / M | 일시정지 / 소리 |

### 📱 휴대폰·태블릿 (터치)

화면을 처음 터치하면 터치 조작으로 바뀝니다.
- **시점**: 주변이 다 보이는 쿼터뷰로 자동 전환됩니다. 조준은 가장 가까운 적에게 자동으로 맞춰집니다.
- **왼쪽**: 누른 곳에 가상 조이스틱이 생기고, 끌면 이동합니다.
- **오른쪽 버튼**: 공격(큰 버튼), 강공, 대시, 무쌍, 터미널. 무쌍·터미널 버튼에는 게이지가 링으로 표시됩니다.
  - 오른쪽 빈 곳을 탭해도 약공격(연타)이 나갑니다.
  - 오른쪽 위 ⏸ 버튼으로 일시정지합니다.
  - 왼쪽 위 무기 바를 탭하면 다음 무기로 바뀝니다.
- **터미널 필살기**: 휴대폰 키보드가 열립니다. **영문 키보드**로 입력하고, "⏎ 실행" 버튼을 누릅니다.
- **메뉴·퀴즈·결과 화면**: 탭으로 선택합니다.
- **성능 모드**: 휴대폰에서는 렌더 해상도, 적 수, 이펙트를 자동으로 줄입니다.
- **권장**: 가로 화면. 세로에서도 동작합니다.
### 📲 홈 화면 앱 · 오프라인 (PWA)

웹 주소(https)로 열면 앱처럼 설치할 수 있습니다.
- **설치 방법**
  - **안드로이드·PC 크롬/엣지**: 타이틀 오른쪽 위 "📲 앱으로 설치" 버튼을 누르거나, 브라우저 메뉴에서 "앱 설치"를 고릅니다.
  - **아이폰·아이패드**: Safari 공유 버튼 → "홈 화면에 추가"
- **실행**: 설치하면 전체 화면 가로 모드로 실행됩니다.
- **오프라인**: 한 번 온라인에서 실행하면 이후엔 오프라인에서도 3D 그대로 동작합니다.
  - Three.js를 `vendor/`에 포함했습니다. cdnjs와 jsDelivr 두 곳에서 받은 파일의 SHA-256이 일치하는 것을 확인했습니다.
  - 제목 글꼴(Black Han Sans)은 한 번 받으면 캐시에서 씁니다. 받기 전 오프라인이면 시스템 글꼴로 대체됩니다.
- **업데이트**: 서비스 워커(`sw.js`)가 캐시를 먼저 보여 주고 뒤에서 새 버전을 받아 둡니다. 그래서 월간 CVE 같은 업데이트는 **다음 실행부터** 반영됩니다. 캐시할 파일을 새로 추가할 때는 `sw.js`의 `CACHE` 이름(`secmusou-v1`)을 올려 주세요.
- **설치가 안 되는 경우**
  - 파일을 직접 여는 경우(`file://`)에는 설치 기능이 꺼지지만, 3D는 로컬 파일로 동작합니다.
  - Claude Artifact 공유 페이지에서는 설치할 수 없습니다(그 페이지는 팀 랭킹 전용).
- **아이콘 다시 만들기**: `node tools/make-icons.mjs`

## 학습 요소

- **거점 6곳 = OWASP Top 10**: 인젝션, 접근통제 실패(IDOR), 암호화 실패, 취약 컴포넌트, 인증 실패, SSRF
  - 거점관리자를 격파하면 도감 카드(설명 · 공격 예시 · 방어법)와 3지선다 퀴즈가 나옵니다. 정답이면 버프를 받습니다.
- **적장 = 실존 CVE 10종**: Log4Shell, Heartbleed, Shellshock, EternalBlue, Spring4Shell, BlueKeep, Zerologon, MOVEit, XZ Utils, Struts2
- **위협 인텔**: 악성코드 유형(웜·랜섬웨어·루트킷 등)을 처음 처치하면 대응법 카드가 잠깐 뜹니다. 전투는 멈추지 않습니다.
- **터미널 필살기**: 실제 보안 명령어 27종(`ufw deny 445/tcp`, `npm audit` 등)과 각 명령이 무엇을 막는지에 대한 설명
- **📘 보안 도감**: 타이틀 메뉴에서 해금한 지식을 복습할 수 있습니다 (브라우저에 저장됨).
- 퀴즈는 타이틀 메뉴에서 OFF로 돌릴 수 있습니다. 끄면 카드만 잠깐 표시됩니다.

## 업그레이드 (v2)

- **무기 6종, 도감을 모으면 해금됩니다** (공부하면 강해지는 구조). 게임 중 숫자키 1~6으로 교체할 수 있습니다.

  | 무기 | 해금 조건 | 특징 |
  |---|---|---|
  | 거대 기계식 키보드 | 기본 | 균형형 |
  | 랜선 채찍 | OWASP 도감 2개 | 사거리 1.6배, 빠름 |
  | 서버랙 해머 | CVE 도감 3개 | 느리지만 피해 2배, 모든 공격이 강타 |
  | 마우스 플레일 | 위협 인텔 5개 | 약공격이 360° 회전베기 |
  | 방화벽 방패 | OWASP 6개 전부 | 정면 피해 60% 감소, 적 탄 반사 |
  | GIJO 블레이드 | 도감 20개 | 전 성능 강화, 게이지 2배 충전 |
- **로그 분석 보스전**: 적장·보스의 HP가 50%가 되면 실제 형식의 로그 한 줄이 나옵니다 (Apache, sshd, Windows 이벤트, DNS 등).
  공격 유형을 맞히면 적이 6초간 그로기 상태가 되어 받는 피해가 2배가 됩니다.
- **보안 점검 요청서 📋**: 75초마다 떨어집니다. 주우면 문제은행(61문제) 퀴즈가 나오고, 정답이면 패치 버프를 받습니다.
- **학습 난이도와 오답노트**: 난이도는 입문, 실무, 심화 중에 고릅니다. 틀린 문제는 다음 판에 더 자주 나오고(간격 반복), 결과 화면에 "오늘의 오답"이 표시됩니다.
- **침해사고 대응 훈련 모드**: 랜섬웨어 사고를 NIST SP 800-61 절차에 맞춰 6단계로 실습합니다.
  - 백업 운반 → 로그 분석 → 격리 명령 입력 → C2 소탕 → 본체 격파 → 관제 구역 사수
  - 단계를 끝낼 때마다 실무 포인트와 흔한 실수 카드가 나오고, 마지막에 사후 보고서 체크리스트를 보여줍니다.
- **직장 스트레스 엘리트 몹**: "긴급 회의 소집", "퇴근 직전 요청", "최종_진짜최종" 등. 처치하면 스트레스 해소율에 보너스가 붙습니다.
- **키보드 축 선택**: 청축, 갈축, 적축에 따라 모든 타격음과 타이핑 소리가 바뀝니다.
- **업적 17종**, **오늘의 CVE**(날짜마다 첫 적장이 정해지며, 격파하면 보너스)

### 콘텐츠 검증 내역 (v2)

GB10이 만든 로그·퀴즈는 모두 사실 확인을 거쳤고, 교정 내용은 `tools/build-content.mjs`에 기록했습니다.
- 로그: 39개 → 32개
  - `{{7*7}}`(SSTI)를 Log4Shell로 표기한 것 → 실제 `${jndi:...}` 페이로드로 교체
  - apache2가 bash를 실행하는 로그를 "정상"으로 표기한 것 → 웹셸 징후로 교정
  - 로그 한 줄만으로는 답의 근거가 없는 문항 7개 제거
- 문제은행: 63개 → 61개
  - 정답 오류 교정: 지문을 "소유 요소"로 표기한 것(→ 생체 요소), 최소 권한 위반 예시, TLS 1.3 문항에 정답이 두 개였던 것
  - 용어 교정: "역설적 저항성" → 역상 저항성
- 미션 시나리오: agy가 기획한 NIST 단계 구성과 교훈을 검토한 뒤 그대로 사용했습니다.

## 🏅 보안팀 랭킹 (공유 페이지)

`artifact.html`을 Claude Artifact로 게시하면 팀 랭킹이 켜집니다. 처음엔 게시한 사람만 볼 수 있고, Share 메뉴에서 팀에 공유합니다.

- 게임이 끝나면 내 최고 기록(종합 점수, 최다 KO, 최대 콤보, 도감 수)과 누적 기록(퀴즈 정답, 판 수, 훈련 수료 횟수)이 자동으로 저장됩니다.
- 순위 기준은 종합 점수, 최다 KO, 보안 도감, 퀴즈 정답 네 가지입니다. 타이틀 메뉴의 "🏅 보안팀 랭킹"에서 ←→로 바꿀 수 있습니다.
- 기록은 `scores/<사용자 id>` 문서에 저장됩니다. 이름은 저장하지 않고 화면에 표시할 때 조회합니다.
- 권한
  - 모두가 랭킹을 볼 수 있지만, 기록은 **참여자(Contributor) 이상**만 남길 수 있습니다.
  - 각자는 **자기 기록만** 바꿀 수 있고, 소유자는 모든 기록을 정리할 수 있습니다.
  - 보기 전용으로 공유받은 사람은 플레이는 되지만 기록은 남지 않습니다.
- 로컬에서 `index.html`로 실행하면 랭킹 없이 게임만 동작합니다.
- 공유 페이지를 갱신할 때는 `artifact.html`을 다시 게시합니다. 게임 파일(`game.js` 등)도 함께 올라갑니다.

## 🆕 월간 CVE 업데이트

매달 CISA KEV(실제 악용이 확인된 취약점 목록)에 새로 추가된 것 중 4개를 골라 게임에 넣습니다.

1. `node tools/cve-update.mjs` 를 실행합니다. 다음 과정이 자동으로 진행됩니다.
   1. 최근 35일 동안 KEV에 추가된 항목 수집 (게임에 이미 있는 CVE는 제외)
   2. agy가 4개를 선정 (기업 사용도, 유형 다양성, 교훈 기준)
   3. NVD에서 CVSS 점수 조회
   4. GB10이 카드·퀴즈 초안 작성
   5. 결과를 `tools/cve-packs/YYYY-MM.draft.json` 에 저장
2. **검수**: 초안을 KEV·NVD 원문과 대조합니다. 원문에 없는 사실은 빼고 퀴즈 정답을 확인한 뒤, `"status": "verified"` 로 `YYYY-MM.json` 에 저장합니다.
3. `node tools/build-content.mjs` 를 실행하면 검수된 팩만 `content.js` 에 합쳐집니다. 그다음 공유 페이지를 다시 게시합니다.

게임에서는 신규 CVE가 오늘의 CVE 다음 적장으로 먼저 나오고, 🆕 KEV 배지가 붙습니다.

- **끄고 켜기**: 타이틀 메뉴 오른쪽 열 맨 아래 "🆕 이달의 신규 CVE: ON/OFF"에서 바꿀 수 있습니다. OFF로 두면 기본 CVE 10종만 적장과 도감에 나옵니다. 설정은 플레이하는 사람마다 브라우저에 저장됩니다.
- **자동 실행 끄기**: 매달 1일 자동 업데이트는 Claude 앱 사이드바의 Scheduled → "보안무쌍 월간 CVE 업데이트"에서 켜고 끌 수 있습니다.

- **2026-11 팩**: vCenter 인증 우회, SonicWall SSLVPN SAML 우회, Chromium UAF, GitLab CI/CD RCE (KEV 2026.11.23 기준)
