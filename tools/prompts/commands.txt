보안 교육용 타이핑 게임에 쓸 "방어 명령어" 36개를 만들어줘. 플레이어가 그대로 타이핑하면 필살기가 나간다.
각 명령은 실제로 존재하는 리눅스/보안 도구 사용법이어야 하고(가짜 옵션 금지), 무엇을 막는지 한국어 설명이 붙는다.

규칙:
- cmd: 10~34자, ASCII만(영문 소문자 위주, 숫자, 공백, - / . _ : = 허용). 따옴표·파이프·세미콜론·대문자 금지.
- desc: 한국어 12~40자, 이 명령이 어떤 공격/취약점을 막는지.
- tag: injection | access | crypto | component | auth | ssrf | malware | network 중 하나.
- 각 tag 최소 3개 이상, 분야를 골고루. 예) "chmod 600 ~/.ssh/id_ed25519" → "SSH 개인키 권한 제한으로 키 탈취 방지"

JSON 배열 하나만 출력(코드펜스·설명 없이):
[{"cmd":"...","desc":"...","tag":"..."}]
