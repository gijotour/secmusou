보안관제(SOC) 교육 게임용 "로그 분석 문제" 36개를 만들어줘. 플레이어는 로그 한 줄을 보고 공격 유형을 3지선다로 고른다.

규칙:
- log: 실제 형식을 따르는 로그 한 줄(최대 150자). Apache/Nginx access log, Linux auth.log(sshd), Windows 보안 이벤트(4625, 4688 등), Sysmon, 방화벽, 프록시, DNS 로그 등 형식을 섞어라. IP는 문서용 대역(203.0.113.x, 198.51.100.x, 192.0.2.x)과 사설망(10.x)만 사용.
- answer: 정답 공격 유형(한국어, 2~12자). choices: 정답 포함 보기 3개(정답 위치 섞기). answerIndex: 정답 인덱스.
- explain: 로그의 어느 부분이 근거인지 한국어로 40~90자.
- level: 1(입문) 2(실무) 3(심화). 각 레벨 12개씩.
- 유형은 골고루: SQL 인젝션, XSS, 경로 탐색, OS 명령 주입, SSRF, Log4Shell(JNDI), 무차별 대입(SSH/RDP), 크리덴셜 스터핑, 웹셸 업로드/실행, 포트 스캔, 디렉터리 스캐닝, XXE, C2 비콘, DNS 터널링, 랜섬웨어 전조(vssadmin 섀도복사본 삭제), 권한 상승, 정상 트래픽(오탐 함정 문제도 3개 포함).

JSON 배열 하나만 출력(코드펜스·설명 없이):
[{"log":"...","choices":["...","...","..."],"answerIndex":0,"explain":"...","level":1}]
